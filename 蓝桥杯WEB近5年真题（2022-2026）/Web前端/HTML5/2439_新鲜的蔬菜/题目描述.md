# 新鲜的蔬菜

## 介绍

厨房里新到一批蔬菜，被凌乱地堆放在一起，现在我们给蔬菜分下类，把相同的蔬菜放到同一个菜板上，拿给厨师烹饪美味佳肴吧。

## 准备

开始答题前，需要先打开本题的项目代码文件夹，目录结构如下：

```txt
├── css
│   └── style.css
├── images
└── index.html
```

其中：

- `css/style.css` 是需要补充代码的样式文件。
- `images` 是图片文件夹。
- `index.html` 是主页面。
