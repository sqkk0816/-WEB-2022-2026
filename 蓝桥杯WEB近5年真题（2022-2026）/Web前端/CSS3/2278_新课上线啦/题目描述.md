# 新课上线啦

## 介绍

最近蓝桥上新了众多优质好课，今天我们将化身蓝桥前端小工，亲自动手制作一个 Java 集训营课程宣传页面，快来一显身手吧。

## 准备

本题已经内置了初始代码，打开实验环境，目录结构如下：

```txt
├── css
│   └── style.css
├── images
├── mark
│   ├── preview
│   └── index.html
└── index.html
```

其中：

- `css/style.css` 是样式文件。
- `images` 是页面布局需要用到的图片素材。
- `mark/preview` 是页面效果图。
- `mark/index.html` 是布局参数标记页面。
- `index.html` 是主页面。

## 目标

请完善 `css/style.css` 和 `index.html` 文件。

请根据 `mark/preview` 最终效果图和 `mark/index.html` 上的参数标注来完成页面布局。

在浏览器打开 `mark/index.html` 页面，鼠标点击页面可以在右侧看到相应的参数标注。

## 规定

- 本题只能使用项目文件夹中提供的素材。
- 请严格按照考试步骤操作，切勿修改考试默认提供项目中的文件名称、文件夹路径等，以免造成无法判题通过。

## 判分标准

- 本题根据页面布局的相似度给分，低于 50% 得 0 分，高于 50% 则通过（正式比赛时会按照比例得分）。
