# 新闻中心

## 介绍

你是一家新闻聚合网站的开发者，该网站的主要功能是从多个新闻源收集新闻并将其展示给用户。你的任务是构建一个功能，该功能需要并发的从各个新闻源获取新闻数据，每个新闻源的数据获取完成后，需对数据进行格式化。在所有新闻源的数据都获取并处理完成后，需要对所有新闻进行排序并展示给用户。另外，请求失败的新闻源会进行二次请求，如果第二次请求成功后可以插入到新闻列表中。

## 目标

在 `index.html` 文件中的 TODO 部分，补足 `getNews` 方法，实现新闻中心从多个新闻源加载新闻的逻辑，具体需要满足以下要求：

1. `getNews` 接收一个参数 `requestUrls` 表示请求新闻源地址数组，发送请求至各个新闻源进行请求，将所有请求成功（ `data` 中的 `code` 为 200，如 `{code:200，data:{}}`）的数据放入新闻列表（ `newsList` ）变量中， 我们需要对新闻列表（ `newsList` ）按照发布时间逆序排序，使最新的新闻位于顶部。将加载状态 `isLoading` 修改为 `false` 。**必须所有请求完成后（请求失败也算完成）才能渲染新闻列表，即全部请求完成后再给 `newsList` 赋值。**

由于每个新闻源返回的数据格式各异，因此在每次请求完成之后，都需要将数据整理成如下格式：

```json
{
	title: string        // 新闻标题  
	content: string    // 新闻内容
	source: string     // 新闻源
	author: string     // 发布者
	createTime: string // 发布时间
}
```
出现的其他字段和规定字段对应如下 `title->name`、`source->from 或 origin`、`createTime->date` 。

2. 如果某个请求失败 （`data` 中的 `code` 不等于 200），如 `{code:400,msg:'请求失败'}`），我们需要在展示新闻列表后针对**所有失败的新闻源**进行一次重试。将获取到的数据存储 `retryNewsList` 变量中。后续点击确定把 `retryNewsList` 插入到新闻列表中，该功能已完成。

**接口文档**

所有接口响应参数格式一致，如下，数据返回成功 `data` 中的 `code` 码为 **200** 。

```js
{ status: number, data: { code: number, msg: string, data: [] } }
```
