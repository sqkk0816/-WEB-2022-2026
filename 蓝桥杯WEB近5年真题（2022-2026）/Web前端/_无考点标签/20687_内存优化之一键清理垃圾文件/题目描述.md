# 内存优化之一键清理垃圾文件

## 介绍

在软件开发中，开发者经常会生成大量临时文件、日志文件、或者编译生成的文件，这些文件可能会占据大量磁盘空间并且没有实际价值。通过编写一个程序来定期清理这些垃圾文件，可以有效的释放磁盘空间并保持开发环境的整洁。下面就请你来完成它吧～

## 准备

开始答题前，需要先打开本题的项目代码文件夹，目录结构如下：

```txt
├── files
├── utils.js
└── index.js
```

其中：

- `utils.js` 是待补充代码的 js 文件。
- `index.js` 是主文件。
- `files` 是放待清理文件的文件夹。

## 目标

请在提供的 `utils.js` 文件下 TODO 部分补全代码，实现以下目标：

1. 实现一个函数 `findGarbageFiles(dirPath)`，接收一个路径 `dirPath`，查找该路径下的所有文件，最终返回文件大小小于 1MB（1024*1024 Byte）的文件。

- 对于每个文件，判断是否为**垃圾文件的标准是文件大小小于 1MB（1024\*1024 Byte）**的文件。
- 对于每个文件夹，递归的应用相同的规则，即对其中的文件和子文件夹进行垃圾文件筛选。
- 所有被识别为垃圾文件的路径和文件大小需要被记录在变量 `garbageFiles` 中最终返回。

其中，`garbageFiles` 的数据结构如下所示：

```js
[
  {
    path: 'xxx/files/Amy.png', // 文件路径
    size: 0 // 文件大小（单位 Byte）
  },
  {
    path: 'xxx/files/Amy.pdf', // 文件路径
    size: 0 // 文件大小（单位 Byte）
  },
  ...
]
```

2. 实现一个函数 `cleanGarbageFiles(garbageFiles)`，接收一个包含垃圾文件路径的数组 `garbageFiles`，并实现一键清理（即，删除）这些垃圾文件。

以上目标完成后，可在终端运行 `node index.js` 命令查看效果。

**提示：fs 模块相关 API**

`fs.readdirSync` 用于读取指定路径下的文件和文件夹列表。

示例：

```js
const folderPath = path.resolve(__dirname, './dist');
const files = fs.readdirSync(folderPath);
console.log(files); // 读取 dist 路径下的文件和文件夹列表
```

`fs.statSync` 用于获取文件或文件夹的详细信息。

示例：

```js
const filePath = path.resolve(__dirname, './index.html');
const fileStats = fs.statSync(filePath);
console.log(fileStats);
```

 `fs.statSync` 方法获取文件的详细信息，并将结果存储在 `fileStats` 变量中。最后，我们输出 `fileStats` 变量的内容，以查看文件的详细信息。

`fileStats` 对象包含了以下常用的属性：

- `fileStats.isFile()`：判断是否是文件。
- `fileStats.isDirectory()`：判断是否是文件夹。
- `fileStats.size`：文件大小。

`fs.unlinkSync` 用于删除文件。

示例：

```js
const filePath = path.resolve(__dirname, './index.html');
fs.unlinkSync(filePath); // 删除文件
```
