# JavaScript 代码规范检查器

## 介绍

JavaScript 是一种广泛使用的编程语言，为了保证代码的质量和一致性，需要有一套规范和标准来指导编写代码。本题提供了一个实现基本 JavaScript 代码规范实时检查功能的工具，可以帮助开发者快速发现并修复代码中的问题，提高代码质量和可维护性。

## 准备

开始答题前，需要先打开本题的项目代码文件夹，目录结构如下：

```txt
├── app.js
├── code.js
└── codeLint.js
```

其中:

- `app.js` 程序启动和监听的 `node` 文件。
- `code.js` 是客户端用户书写 js 代码。
- `codeLint.js` 是待补充的 `node` 文件。

运行 `node app.js`，会显示如下效果：

```bash
🌟 恭喜，你已成功运行 app.js！ 🚀
```

改动 `codeLint.js` 后保存（`ctrl+s`）文件，无需重新运行 `node`，会自动运行当前文件。效果如下：

```bash
代码已保存，重新启动应用...
```

## 目标

请在 `codeLint.js` 文件中的 TODO 部分，完善 `checkCode` 函数，实现代码规范检查。

**函数功能说明：**

`checkCode` 函数用于实时检查 JavaScript 代码的规范性。该函数接收一个名为 `code` 的参数表示 `code.js` 文件的内容。

函数返回值为包含代码中存在问题的数组 `issues`。`issues` 数组的规则是：每个元素都必须是一个对象，并且只能包含以下两个属性： `lineNumber` 是问题所在行的行号， `message` 是问题的具体描述。

`issues` 数组格式示例：

```js
[
    { lineNumber: 3, message: '变量 variableA 定义未使用' },
    { lineNumber: 13, message: '避免在生产代码中使用 console' }
  ]
```

`checkCode` 函数需要完成以下目标：

1. 如果在代码中使用了 `console`，则将 `message` 设为 "避免在生产代码中使用 console"。
2. 如果使用了 `var` 关键字来声明变量，则将 `message` 设为 "禁止使用 var 声明变量，推荐使用 let 或 const"。
3. 如果定义了但是没有使用的变量，则将 `message` 设为 "变量 variableA 定义未使用"，并用实际的变量名替换 `variableA`，可以使用已提供的 `getVarName` 函数获取当前行的变量名。
4. 函数的返回值 `issues` 数组需要**按照行号 (`lineNumber`) 从小到大的顺序升序排列**，如果没有发现问题，则返回一个空数组。

测试用例如下，**需要注意检测时会使用不同的测试数据，请注意代码的通用性**：

- 已提供的 `code.js` 中的代码，`checkCode` 函数运行结果如下：

```js
[
  { lineNumber: 1, message: '变量 newVariableA 定义未使用' },
  { lineNumber: 3, message: '禁止使用 var 声明变量，推荐使用 let 或 const' },
  { lineNumber: 8, message: '变量 newElement 定义未使用' },
  { lineNumber: 12, message: '避免在生产代码中使用 console' }
]
```
